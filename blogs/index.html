Quick help

Open a post: Use ?id=blog003 (replace with any blog id). Example: / (index), /?id=blog003.

TTS: Press t or the Play button. Bottom bar is the single TTS control. Highlight follows what is being read. Use the slider to jump. Settings and progress persist.

Reading ruler: Turn on in the hub. It shows a soft band in the viewport to help focus; a one-time tutorial will appear the first time you enable it.

Images: Images are used as your JSON points them to. If an image 404s it will quietly fall back to an inline placeholder logo, avoiding broken icons.

Extras: Export markdown, copy permalink, printable view via browser print. Keyboard shortcuts are listed in the hub.
