How to use this reader

Open a post

Use a URL with the query param ?id=blog003 (replace with the id you want). Example: https://yoursite.example/?id=blog003. This file only uses query routing so links generated by the reader always use ?id=.

Images and paths

The reader will try to load images referenced in your JSON in this order:

  1. If the JSON path starts with http or // or a starting slash /, it uses it directly.
  2. If the path is relative (like pictures/image.png), it will try resolving relative to the current page's directory (where index.html is located).
  3. Then it tries resolving relative to the blogs.json file location (in case your JSON lives beside the blogs).
  4. If all of the above fail, it falls back to logo.png.

Text to Speech (TTS)

Press the top right Play button or use t to toggle play/pause. The reader splits the article into short segments and highlights the sentence currently being read. You can change voice, speed, and volume in the TTS controls that appear above the article. Progress, rate, voice, and last-read segment are saved so you can resume later.

Reading ruler

Enable the Reading ruler in the menu to get a soft band across the page that helps focus. It tracks your viewport and follows as you scroll.

Accessibility & Preferences

Open the menu (hamburger or m) to change text size, spacing, font, contrast, and reduced motion. These preferences persist in localStorage.

Other features

  • Copy permalink to currently open post (menu).
  • Export the post to Markdown (menu) for quick notes.
  • Printable view with the Print button.
  • Keyboard shortcuts listed in the menu.

Troubleshooting

  • If an image 404s, check filename case sensitivity and whether the path is relative to the blog file or the site root.
  • If TTS fails in some browsers, try selecting a different voice in the TTS controls (some voice engines reject certain characters).
